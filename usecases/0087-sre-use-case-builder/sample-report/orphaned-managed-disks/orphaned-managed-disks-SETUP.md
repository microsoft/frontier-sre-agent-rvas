## Step 1 - Permissions for the agent managed identity

All access is read-only except publishing the report. Run in Azure Cloud Shell (bash) unless stated otherwise.
Find the identity in the Azure portal: the agent's resource group > managed identity `id-…` (the SRE Agent portal has no
Settings menu anymore). Its **Overview** page shows the **Client ID** and the **Object (principal) ID** used below.

**1. Reader** - scope `/subscriptions/<subscription id>` - read resources for source 'disks'

```bash
az role assignment create --assignee-object-id <agent managed identity principal (object) id> --assignee-principal-type ServicePrincipal --role "Reader" --scope "/subscriptions/<subscription id>"
```

Role assignments take 5-10 minutes to apply; Microsoft Graph app roles can take up to 30 minutes.

## Step 2 - Python tool

**Build + configure > Agent Canvas > Create ▾ (the arrow next to Create) > Tool › Python tool**

On the **Code** tab:

- **Tool Name:** `run-orphaned-managed-disks` (36 characters at most)
- **Timeout (seconds):** `300` (default 120, maximum 900)
- **Description:** block 1 of `orphaned-managed-disks-BUILDER-BLOCKS.md`
- **Code:** Ctrl+A in the editor and paste the whole `run-orphaned-managed-disks.py`. Only edit the `CONFIG = {...}` section if you need to change queries, thresholds or rules.

There is no parameter editor: the parameters come from `def main(...)` in the code.

| Parameter | Type | Default | Description |
|---|---|---|---|
| `mode` | string | report | report = full branded HTML + PDF + CSV/JSON report; discover = read a few live rows per source and list columns (no report); self_test = simulated data, no Azure calls, proves the logic and HTML |
| `publish` | string | no | yes = also upload the report and its snapshot to the configured SharePoint/Blob target (history for next comparison); no = thread only |
| `lookback_days` | integer | 0 | Days of data to analyse; 0 = CONFIG default |

On the **Identity** tab, leave **Enable Azure Identity** Off: the code gets its own token for the agent managed identity
(`ManagedIdentityCredential(client_id=…)`). Do not switch it on to look: it inserts four lines at the top of the code, and they
stay there when you switch it off (delete them if that happens).

**Create tool** stays grey until you run a test. The **Test playground** tab has one empty box per parameter (empty = default):
type the values and click **Test**, in this order:

1. `mode` = `self_test` -> `status: SIMULATED` and an HTML link (proves the logic without Azure access).
2. `mode` = `discover` -> every `sources[].status` is `OK` and you see the expected columns. A `FORBIDDEN` means step 1 is missing.
3. `mode` = `report`, `publish` = `no` -> `status: OK`, KPIs and findings make sense, open the HTML.
4. `mode` = `report`, `publish` = `yes` (only if publishing is configured) -> `published[].status: OK`.

Then click **Create tool**.

## Step 3 - Skill

**Create ▾ > Skill**

1. Paste the whole SKILL.md of block 2 in the **SKILL.md** editor **first**: its front matter fills **Name** (`orphaned-managed-disks`) and **Description**.
2. **Choose tools**: search `run-orphaned-managed-disks`, expand **PythonFunctionTool**, tick only `run-orphaned-managed-disks` and click **Close panel**.
3. Check the tool chip and the `tools:` line in the front matter, then click **Create**.

Choose the tool after pasting: pasting the whole SKILL.md replaces the front matter and drops a tool chosen before.

## Step 4 - Subagent

**Create ▾ > Custom agent** (the **Create** button opens the same **Create a custom agent** form)

- **Custom agent name:** `orphaned-managed-disks`
- **Instructions:** block 3
- **Choose skills:** tick only `orphaned-managed-disks`, then **Close panel**
- **Choose tools:** search `run-orphaned-managed-disks`, expand **PythonFunctionTool**, tick only `run-orphaned-managed-disks`, then **Close panel**

**Tools & skills** (**Skills**, **Python tools**).

## Step 6 - Scheduled task

**Automation > Create ▾ > Scheduled task**

- **Task name:** `orphaned-managed-disks-weekly`
- **Response subagent:** `orphaned-managed-disks`
- **Task details:** the prompt of block 4
- **Frequency:** **Custom cron**, **Cron expression (UTC)** `0 7 * * 1` (or the equivalent Daily/Weekly/Monthly option; its time list is in your local time zone)
- **Message grouping for updates:** **New chat thread for each run**

Leave Start on, Repeat until, Model tier, Set a run limit and Agent autonomy level as they are, and click **Create task**.

**Test playground**, then **Save** (it stays grey until you run a test).
To regenerate everything, open a **New chat**, pick `sre-usecase-builder` with `/agent` and paste the spec in `orphaned-managed-disks-spec.json`.
