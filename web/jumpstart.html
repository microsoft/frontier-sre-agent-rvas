RVAS — Azure SRE Agent

SRE Agent Jumpstart Skill

An installable Copilot CLI plugin that interviews you about an operational need, researches the right Azure SRE Agent building blocks, and generates a reviewable plan — then, once you approve it, authors the skill YAML, knowledge docs, subagent configuration, or capability manifests for you. Useful as an optional accelerator for Challenge 19 and the SQL Server DBA capstone.

Install the plugin

Add this repository as a plugin marketplace, then install the plugin. This also registers the microsoft-learn MCP server, which the azure-sre-agent skill uses to fetch current Azure SRE Agent documentation — no separate MCP setup needed.

Terminal 
copilot plugin marketplace add microsoft/frontier-sre-agent-rvas
copilot plugin install rvas-sre-agent-jumpstart@rvas-sre-agent-jumpstart

Install the dependency skills

The jumpstart skill activates two companion skills by name during its interview and research steps: grilling (structured interview protocol) and azure-sre-agent (the Azure SRE Agent documentation pointer skill). Install both with the gh skill install command.

Terminal 
gh skill install mattpocock/skills skills/productivity/grilling --agent github-copilot
gh skill install MicrosoftDocs/Agent-Skills skills/azure-sre-agent --agent github-copilot

gh skill install is a preview GitHub CLI command and may change; re-run gh skill install --help if either command stops working as documented.

When to use it

Both capstones ask you to design a production-ready SRE Agent capability from scratch. The jumpstart skill is an optional accelerator in each — it does not replace or widen either track's existing trust boundaries or Success Criteria.

  • Challenge 19 — Build Your Own Production-Ready SRE Agent: use it after you've sketched your design (Step 2) to draft the skill YAML, knowledge doc, and subagent configuration for Step 3.
  • SQL Server DBA Challenge 09 — Build Your Own SQL Server DBA Agent: use it if your scenario would benefit from packaging as a reusable skill or subagent alongside the supplied read-only sqlserver-mcp connector.
