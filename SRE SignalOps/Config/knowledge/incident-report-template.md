# SignalOps incident report

Record:

- Incident ID, severity, affected resources and customer impact.
- UTC detection, investigation, approval, recovery and verification timeline.
- Observed evidence, including query windows, resource/revision IDs and metrics.
- Hypotheses tested, confidence, root cause and contributing factors.
- Knowledge documents used; separate durable guidance from current observations.
- Proposed actions, explicit approvals, executed changes and their scope.
- Recovery evidence from endpoints, telemetry and alert state.
- Remaining risks, follow-up owners and prevention recommendations.

Never include credentials, access tokens, private keys or sensitive customer data.
