# Issue triage policy

The lab has no default external issue repository or GitHub connector. Prepare a
local recommendation unless the operator explicitly selects a repository and
authorizes access. Do not infer a repository from application names or paths.

Before filing, search the approved repository for duplicates. Include impact,
reproduction boundaries, UTC incident window, sanitized evidence, root-cause
confidence, recovery verification and an actionable acceptance criterion.
Exclude tokens, connection strings, state, private addresses not approved for
publication, and customer data. Ask for approval before creating or modifying
issues; distinguish a proposed issue from one actually created.
